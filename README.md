# WDD430 Portfolio

A simple portfolio site built with Next.js (App Router), TypeScript and Tailwind CSS.

## Live site

Deployed on Vercel: https://portfolio-buchimond.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Pages and routes

- `/` - Home (project list)
- `/about` - About page with a custom SkillsCard component
- `/api/hello` - Simple API route
